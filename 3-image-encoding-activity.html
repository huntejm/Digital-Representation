Pixel Painter

A digital image is a grid of pixels, and every pixel is just a stored number representing a color. More colors per pixel means more bits — and more bits means a bigger file.

Discussion Questions

  1. A photo-realistic image needs way more than 8 colors. Roughly how many bits per pixel does a "true color" (16.7 million color) image need? (Hint: it's 3 bytes — one per red, green, blue channel.)
  2. If you doubled the grid from 8×8 to 16×16, what happens to the total storage needed? Why?
  3. Image formats like JPEG use "lossy" compression — they throw away some pixel data to save space. What's the tradeoff being made there?
