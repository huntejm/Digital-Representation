What Happens When We Run Out of Bits?

An 8-bit byte tops out at 255. Adding one more overflows back to 0 — unless we add more bits.

8 bits0–255256 values
16 bits0–65,53565,536 values
32 bits0–4.29 billion~4.3B values

Discussion Questions

  1. If n bits can represent 2n values, how many bits would you need to give every student in your school a unique ID number?
  2. Why do you think early computers used 8-bit bytes instead of, say, 10-bit or 100-bit units?
  3. What tradeoff is a computer engineer making when they choose to store a number using more bits vs. fewer bits?
