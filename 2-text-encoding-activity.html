Discussion Questions

  1. Classic ASCII only used 7 bits per character — 128 possible symbols. Why wasn't that enough for the whole world?
  2. Unicode now supports over 140,000 characters, including emoji. What tradeoff comes with supporting that many symbols?
  3. If a text file is "just numbers," what does that tell you about the difference between a text file and, say, a program that stores numbers for a calculator?
